# farooq-majeed-portfolio

Personal developer portfolio for **Farooq Majeed** — Frontend Developer & UI/UX Specialist focused on responsive interfaces, cross-browser QA, accessibility auditing, and Core Web Vitals optimization.

## Stack

- Semantic HTML5 (including native `<dialog>` case-study modals)
- Modern CSS (`light-dark()`, scroll-driven progress bar, `@starting-style`, `prefers-reduced-motion`)
- Vanilla ES6+ JavaScript (no frameworks or build step required)

## Local preview

Serve the root folder with any static HTTP server, or open `index.html` directly in a modern browser.
